# Ama's Plant Corner

## 1. Project Overview

Ama's Plant Corner is a small plant shop in Accra, Ghana. This project rebuilds the shop's website to make it more welcoming, easier to navigate, and responsive on mobile phones and desktop computers.

**Business address:** 14 Okaishie Lane, Accra, Ghana

## 2. Project Goals

- Create a calm and welcoming website for the business.
- Make the website easy to use on phones and computers.
- Help visitors find products, plant advice, and shop information.
- Use semantic HTML and accessible navigation.
- Create a consistent visual design using natural colours.

## 3. Problems Addressed

The redesign focuses on common problems that can make a small-business website difficult to use:

- Poor usability on small screens.
- Inconsistent spacing and visual presentation.
- Unclear navigation and shop information.
- Accessibility issues for keyboard users.

These are the problems this redesign aims to address; they should be compared with the original website as part of the project diagnosis.

## 4. Design Choices

### Colour Palette

- Dark green: `#2f4f3a`
- Soft green: `#dfe9dc`
- Warm cream: `#f8f5ed`
- Dark text: `#26332a`
- White: `#ffffff`

The green colours reflect plants and nature, while the cream background gives the page a warm appearance.

### Typography

Arial is used as the main font because it is familiar and readable on most devices.

### Layout and Spacing

The page uses a centred main content area, consistent spacing, white product cards, and a mobile layout that stacks the cards vertically on smaller screens.

## 5. Technologies Used

- HTML5

## 6. Website Features

- Business header and navigation.
- Introduction section with a shop link.
- Product categories for houseplants, pots, and soil.
- Plant advice section.
- Shop address and visit information.
- Responsive layout for mobile devices.
- Visible keyboard focus indicators.
- A skip link that allows keyboard users to bypass navigation.
- Reduced-motion support for visitors who prefer less animation.

A skip-to-main-content link was added to help keyboard users reach the main content without navigating through every menu link.

Reduced-motion CSS was also included to respect visitors who prefer fewer animations.
